Next.js로 정적 블로그 만들기

정적 블로그는 성능이 뛰어나고 GitHub Pages에서 호스팅하기 쉽습니다.

주요 특징

  • 빠른 성능: 사전 생성된 정적 HTML
  • SEO 친화적: 검색 엔진에 최적화됨
  • 무료 호스팅: GitHub Pages 활용
  • 마크다운 지원: 간편한 글 작성

기술 스택

// Next.js 설정 예제
const config = {
  output: 'export',
  basePath: '',
  unoptimizedImages: true,
};

빌드 방법

npm run build

빌드 결과물은 out/ 디렉토리에 생성됩니다.

GitHub Pages 배포

GitHub Actions를 통해 자동으로 배포할 수 있습니다.

이 블로그는 다음을 지원합니다:

  1. 태그 필터링: 관심 있는 주제별로 검색
  2. 카테고리 관리: 주제별 분류
  3. 월별 아카이브: 날짜별 검색
  4. 디자인: Tailwind CSS로 아름답게 스타일링

더 많은 기능을 추가할 수 있습니다!
