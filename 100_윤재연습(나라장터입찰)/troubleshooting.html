⚠️ 나라장터 API 문제 해결 가이드

🔴 현재 발생하는 문제

  • HTTP 500 Error: "Unexpected errors" - 파라미터 또는 엔드포인트 문제
  • HTTP 404 Error: "Not Found" - 잘못된 API URL 또는 미승인된 서비스
  • 조회 반응 없음: API 호출이 실패하거나 프록시 서버 문제

📋 문제 원인 분석

가능한 원인들:

  1. 잘못된 API 서비스 신청
    • "조달청_나라장터 낙찰정보서비스"가 아닌 다른 서비스를 신청했을 가능성
    • Base URL이 /as/를 포함하는지 확인 필요
  2. 필수 파라미터 누락
    • 일부 API는 특정 파라미터가 반드시 필요함
    • 날짜 파라미터 형식이 잘못되었을 수 있음
  3. API 승인 상태 문제
    • 승인은 되었지만 특정 API만 사용 가능할 수 있음
    • 상세기능 선택을 잘못했을 가능성

✅ 해결 방법

Step 1: API 승인 상태 정확히 확인

  1. 공공데이터포털 마이페이지 접속
  2. "오픈API > 개발계정 상세현황" 클릭
  3. 신청한 API 서비스의 정확한 이름을 확인:
    • ✅ "조달청_나라장터 낙찰정보서비스" (ID: 15129397)
    • ❌ "조달청_나라장터 입찰공고서비스" (다른 서비스)
  4. 승인 상태가 "승인"인지 확인
  5. 어떤 상세기능을 선택했는지 확인 중요!

Step 2: 정확한 엔드포인트 확인

공공데이터포털에서 해당 API 페이지의 "상세기능정보" 탭을 확인하세요:

엔드포인트명 URL 용도
개찰결과 용역 목록 조회 /getOpengResultListInfoServc 기본 용역 개찰결과
나라장터 검색조건별 /getOpengResultListInfoServcPPSSrch 상세 검색 조건 사용
낙찰된 목록 현황 /getScsbidListSttusServc 낙찰 현황

Base URL: https://apis.data.go.kr/1230000/as/ScsbidInfoService

⚠️ /as/ 경로가 포함되어야 합니다!

Step 3: API 재신청 (권장)

현재 API가 제대로 작동하지 않는다면, 다시 신청하는 것이 가장 확실합니다:

  1. 나라장터 낙찰정보서비스 페이지로 이동
  2. "활용신청" 버튼 클릭
  3. 상세기능정보에서 다음 API들을 선택:
    • ✅ 개찰결과 용역 목록 조회
    • ✅ 나라장터 검색조건에 의한 개찰결과 용역 목록 조회
    • ✅ 낙찰된 목록 현황 용역조회
  4. 활용목적 작성 (예: "용역 계약 개찰결과 분석 및 통계")
  5. 신청 후 1-2일 대기
  6. 승인 후 새로운 API 키로 다시 시도

Step 4: 임시 대체 방법

API 승인을 기다리는 동안 다음 방법을 사용할 수 있습니다:

  1. 나라장터 웹사이트에서 직접 검색
    • 나라장터 → 낙찰정보 → 개찰결과 → 검색
    • 업종코드: 1121 입력
    • 기간: 2025-01-01 ~ 2025-12-31
    • 결과를 수동으로 다운로드 (Excel 등)
  2. 조달청 고객센터 문의
    • 전화: 1588-0800
    • API 사용 관련 문의
    • 올바른 엔드포인트와 파라미터 확인
