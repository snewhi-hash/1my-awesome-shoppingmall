🔍 나라장터 API 키 검증 도구

⚠️ API 500 에러 해결 방법

현재 상황: API 호출 시 "HTTP Error 500: Internal Server Error" 발생

주요 원인:

  1. API 사용 신청이 아직 승인되지 않음 (가장 흔한 원인)
    • 공공데이터포털에서 신청 후 보통 1-2일 소요
    • 승인 전에는 API 호출이 불가능합니다
  2. 잘못된 API 키 사용
    • 일반인증키(Encoding)와 일반인증키(Decoding) 중 올바른 키 사용
    • 공백이나 특수문자가 포함되지 않았는지 확인
  3. 잘못된 API 서비스명
    • "조달청_나라장터 낙찰정보서비스"를 신청했는지 확인
    • 다른 서비스(예: 입찰공고)를 신청한 경우 다른 엔드포인트 사용

📋 1. API 승인 상태 확인하기

  1. 공공데이터포털 마이페이지 접속
  2. "오픈API > 개발계정 상세현황" 메뉴 클릭
  3. "조달청_나라장터" 관련 API의 승인상태 확인
  4. 승인상태가 "승인"이 아니면 API 사용 불가

📞 3. 사용 가능한 대체 방법

  1. API 승인 대기 중:
    • 조달청 콜센터: 1588-0800
    • 공공데이터포털 문의: 1661-2966
  2. 즉시 사용하려면:
    • 나라장터 웹사이트에서 직접 검색
    • 수동으로 데이터 확인 및 수집
  3. 다른 API 서비스:
    • "조달청_나라장터 입찰공고서비스" 신청 (별도 서비스)
    • 각 서비스마다 별도 신청 및 승인 필요

✅ 4. 올바른 API 신청 방법

  1. 공공데이터포털 접속 및 로그인
  2. 검색창에 "나라장터" 검색
  3. 필요한 서비스 선택:
    • 조달청_나라장터 낙찰정보서비스 (낙찰/개찰 결과 조회)
    • 조달청_나라장터 입찰공고서비스 (입찰 공고 조회)
  4. "활용신청" 버튼 클릭
  5. 상세기능정보에서 필요한 API 선택 (예: "개찰결과 용역 목록조회")
  6. 활용목적 작성 후 신청
  7. 1-2일 대기 (승인 완료 후 이메일 알림)
  8. 승인 후 "마이페이지"에서 인증키 확인
